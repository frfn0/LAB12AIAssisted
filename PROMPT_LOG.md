### Результат

CRUD-приложение на FastAPI по основной сущности предметной области
(книга). Модель данных из 6 полей, эндпоинты `GET/POST /items`,
`GET/PUT/DELETE /items/{item_id}`, валидация через Pydantic v2,
обработка ошибок, type hints.

Структура кода разделена по ответственности: `config.py` — настройки,
`database.py` — подключение и сессии, `models.py` — модели SQLAlchemy,
`schemas.py` — схемы Pydantic, `errors.py` — доменные исключения,
`api/items.py` — маршруты, `main.py` — сборка приложения. Каждый модуль
не знает о соседних больше, чем требуется.

### Неудачная попытка и исправление

| Что пошло не так | Почему | Как исправлено |
|------------------|--------|----------------|
| Поиск `search=булгаков` не находил книгу «Булгаков М.А.» | `lower()` в SQLite меняет регистр только для ASCII | В `app/database.py` на соединение SQLite регистрируется Unicode-функция `lower()` на Python, `ilike()` подхватывает её автоматически |
| Приложение не импортировалось: `ModuleNotFoundError: No module named 'email_validator'` | Pydantic требует `email-validator` для поля `EmailStr` | Добавлено `pydantic[email]` в `requirements.txt`, пакет установлен |
| `Set-Content` записал `__init__.py` в кодировке консоли, Python не смог прочитать файл | PowerShell 5.1 пишет текст в OEM-кодировке | Файлы с русским текстом создаются инструментом записи, а не `Set-Content` |

### Неудачные попытки и исправления

| Что пошло не так | Почему | Как исправлено |
|------------------|--------|----------------|
| `test_поиск_находит_несколько_книг` получал одну книгу вместо двух | В тесте не использовалась фикстура `created_book`, первая книга не создавалась | Добавлена фикстура `created_book` в список аргументов теста |
| Тесты на тексты сообщений падали | Приложение писало «4 экземпляров» вместо «4 экземпляра» — ошибка согласования числительного | Сообщения переписаны в форму, не требующую согласования: «в выдаче 4 шт.» |
| Тесты видели пустую базу | SQLite создаёт новую базу в памяти на каждое соединение | В `app/database.py` для подключения в памяти добавлен `StaticPool` |
| `ModuleNotFoundError: No module named 'email_validator'` при импорте схем | Pydantic требует пакет для `EmailStr` | В `requirements.txt` указано `pydantic[email]` |
| Имена тестов на русском требовали `non-ascii` при передаче через PowerShell | Кодировка консоли CP866 | Файлы тестов созданы инструментом записи в UTF-8, запускаются через `python -m pytest` |

### Проверка

`app/api/items.py` 100%, `TOTAL` 97%.
